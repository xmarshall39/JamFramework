# JamFramework
A small Unity toolkit for Game Jam essentials! 

Jam Framework provides basic, template implementations of common game jam needs. The kinds of boilerplate features that gets rewritten on nearly every project. We call these `Subsytems`. With game jams being the target products, each Subsystem is built to provide the bare minimum, leaving you room to design game-specific features on top of a common baseline.

## Installation
- [Add package](https://docs.unity3d.com/Manual/upm-ui-giturl.html) from git URL: `https://github.com/yCatDev/uimgui-extended.git` (for debug menu functionality)
- Add package from git URL: `https://github.com/xmarshall39/JamFramework.git` or add from tarball using the lastest from the Releases tab

## Subsystems
Subsystems typically priortize features that exist "around" your game — either supporting backend functionality or common tertiary gameplay features. Most subsystems can function as independent modules, and their use is up to the developer's discretion. Not every project will use every module, however those bolded below are strongly recommended for any project. 

Subsystems include the following:
- **Audio System**
- Scene Manager
- **Debug Menu**
- Main Menu
- **Persistent Bootstrap Scene**
- Platform-Specific Gameobject Config
- Gameplay Timer
- And More!

The full list of subsystems and documentation for each can be found on the Wiki.
